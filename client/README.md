# Short URL Frontend

ใช้ Vue, Vite และ CSS พร้อมไลบรารี qrcode

อ่านวิธีติดตั้งทั้งระบบ สร้างฐานข้อมูล ตั้งค่าแวดล้อม รันโปรเจกต์ และสถานะ Login/Sign up ใน [README หลัก](../README.md)

รันจากโฟลเดอร์ client หลังติดตั้ง dependencies และเปิด Backend พอร์ต 3000:

```powershell
npm.cmd run dev
```

Build:

```powershell
npm.cmd run build
```

ผลลัพธ์อยู่ใน client/dist เปิดผ่าน Express ตามคู่มือหลัก ไม่ใช่เปิด index.html โดยตรง

เว็บออนไลน์: https://short-url-4xil.onrender.com
