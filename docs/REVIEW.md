## สิ่งที่ยังต้องยืนยัน

สถานะล่าสุด: browser handoff commit 7f09f71 Deploy และเปิดโหมดแล้ว ผู้ใช้ยืนยัน Location ไปบริการ Redirect และเปิดลิงก์หลังพัก 15 นาทีผ่านในรอบใช้งานที่รายงาน ดูหลักฐานและขอบเขตที่ [ผลล่าสุด](SUBMISSION.md#ผลออนไลน์ล่าสุดในโหมด-browser) ส่วน checklist ค้างของรอบก่อนด้านล่างให้อ่านร่วมกับผลล่าสุด ไม่ถือว่าออนไลน์ยังใช้ proxy

- ผลพัฒนา browser handoff: ชุดทดสอบ 5/5 ผ่าน local/proxy/browser, สิทธิ์เจ้าของ, GET พร้อมกัน, HEAD, หมดอายุ/ลบ และ Browser Desktop/Mobile พร้อมหน้าถูกลบและปุ่มกลับบริการหลัก ผลนี้เป็นหลักฐานก่อน Merge ไม่ใช่การรันทดสอบใหม่ในรอบเอกสาร
- คำยืนยันออนไลน์เพิ่มเติมก่อน browser: ค้นหา/ประวัติไม่ข้ามบัญชี แก้ชื่อแล้ว URL/QR เดิมเปิดได้ แบ่งหน้าและค้นหาข้ามหน้า ลิงก์เก่าคลิกเพิ่ม HEAD คลิกคงเดิม ลบคลิกคงเดิมใน DB และปฏิเสธรหัสซ้ำครบสามสถานะ

- คู่มือติดตั้งใช้ main; ผู้ใช้ทดลอง clone ใหม่ short-url-final-check กับฐานข้อมูล short_url_final_check และพอร์ต 3070/3071 ในโหมด browser ผ่าน migration, Build, รันสอง process, สร้างลิงก์, เปิด YouTube และแสดงคลิก 1 แล้ว ดู [ผลติดตั้งใหม่](SUBMISSION.md#ผลติดตั้งใหม่จาก-clone-ล่าสุด)
