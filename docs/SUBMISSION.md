# ผลทดสอบและรายการเตรียมส่งงาน

## สถานะ

วันที่ 16 ตุลาคม 2026 ผู้ใช้ยืนยัน migration และทดสอบออนไลน์ผ่าน โดยเฉพาะ QR บนมือถือกับการแยกสองบัญชี นี่คือคำยืนยันของผู้ใช้ ไม่ใช่ผลออนไลน์ใหม่ที่ผู้ช่วยทดสอบในรอบเอกสาร

ชุดทดสอบ [auth.test.js](../server/tests/auth.test.js) ครอบคลุม migration, สมาชิก, session, CSRF, rate limit, แยกเจ้าของ, Redirect และ pagination รัน `npm.cmd test --prefix server` กับ PostgreSQL ในเครื่อง ส่วน `npm.cmd run build --prefix client` ตรวจ Build Frontend ไม่แทนการทดสอบใช้งาน

## ลำดับสาธิต

1. เปิดเว็บและอธิบาย Vue → Express → PostgreSQL ตาม Architecture
2. สมัคร Login สร้างลิงก์ คัดลอกเปิดปลายทาง สแกน QR มือถือและดาวน์โหลด PNG
3. รีเฟรชประวัติแสดงคลิกเพิ่ม อธิบายว่ารวมเปิดซ้ำ ไม่ใช่จำนวนคน
4. สลับสองบัญชีแสดงประวัติแยก Logout แล้วต้อง Login ใหม่
5. แสดง pagination ด้วยอย่างน้อย 11 รายการในบัญชีเดียว พร้อม ER/DFD และวิธีติดตั้ง
6. อธิบายข้อจำกัดและฟังก์ชันเสริมที่ทำจริง หลีกเลี่ยงแสดง Environment, cookie และรหัสผ่านระหว่างนำเสนอ

## ผลรอบฟังก์ชันใหม่ (ในเครื่อง)

Build ผ่าน ชุดทดสอบ PostgreSQL schema แยกครอบคลุม migration ซ้ำ รหัสซ้ำ/ผิดรูปแบบ วันหมดอายุ แก้ชื่อและสิทธิ์เจ้าของ ค้นหาข้ามหน้าแบบ literal และ HTTP 410 ไม่เพิ่มคลิก ตรวจ Browser จริง Desktop/Mobile: Login สร้างลิงก์ ค้นหา แก้ชื่อ Logout และหน้าหมดอายุ ไม่พบ horizontal overflow ไม่มีผลออนไลน์ชุดใหม่จนกว่าจะ migration และ Deploy

การลบ: ทดสอบสิทธิ์เจ้าของ/CSRF การลบซ้ำ การซ่อนประวัติและค้นหา แก้ชื่อหลังลบไม่ได้ GET/HEAD ตอบ 410 ไม่เพิ่มคลิก และ code ยังคงถูกจอง ไม่ได้ลบข้อมูลจริงออกจากฐานข้อมูล

ผู้ใช้ยืนยันว่าทดสอบฟังก์ชันชุดใหม่ในเครื่องผ่านแล้วในบทสนทนา หลังเพิ่มการลบพบ Backend พอร์ต 3059 ยังเป็นโค้ดเก่า จึงรีสตาร์ตและตรวจ API จริง: สร้างลิงก์ → ลบตอบ 204 → เปิดลิงก์เดิมตอบ 410 ผ่าน ผลทดสอบนี้ไม่ใช่การยืนยันบน Render
